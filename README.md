# Projeto ITR

Projeto de análise exploratória de dados sobre arrecadação do Imposto Territorial Rural (ITR).

## Tecnologias
- Python 3.10+
- Pandas
- NumPy
- Matplotlib

## Estrutura

projeto/
├── data/
│   ├── raw/
│   └── processed/
├── notebook/
├── relatorio.pdf
├── README.md
└── requirements.txt

## Como executar

1. Instale as dependências: "pip install -r requirements.txt";

2. Abra o Jupyter Notebook, ele se encontra em: "notebook/projeto_itr.ipynb";

3. Execute as células em ordem.

## Dataset
Os dados foram obtidos a partir do portal de dados abertos do Governo Federal: 
<https://dados.gov.br/dados/conjuntos-dados/resultado-da-arrecadacao>.

Caminho utilizado: Recursos → Arrecadação de ITR detalhada.
